# Дело Ритма — демоверсия сайта

Готовая статическая демоверсия для GitHub Pages.

## Что есть в демо
- Страница выбора смены лагеря.
- Форма тестовой заявки на ребёнка и родителя.
- Панель администратора в том же интерфейсе.
- Добавление и закрытие смен.
- Изменение статусов заявок.
- Экспорт заявок в CSV.
- Адаптивная вёрстка для телефона и компьютера.

## Публикация на GitHub Pages
1. Распакуйте архив.
2. Загрузите **все файлы из этой папки** в корень репозитория `JonyMrZoom/Dcamp`.
3. Убедитесь, что главный файл называется `index.html`.
4. В GitHub откройте Settings → Pages.
5. В разделе Build and deployment выберите Deploy from a branch.
6. Branch: `main`, folder: `/ (root)`, нажмите Save.
7. Через несколько минут сайт будет доступен по адресу:
   https://jonymrzoom.github.io/Dcamp/

## Важное ограничение текущей версии
Это фронтенд-прототип без серверной базы и авторизации администратора.
Заявки и изменения смен сохраняются в localStorage текущего браузера.
Они не синхронизируются между устройствами и не отправляются организаторам.
Для проверки используйте только вымышленные данные, не вводите реальные персональные данные детей.

## Структура
- `index.html` — весь интерфейс и логика демоверсии.
- `.nojekyll` — отключает обработку GitHub Pages через Jekyll.
